# Security policy

Do not report suspected vulnerabilities through a public issue. Use the
repository's private GitHub Security Advisory flow so maintainers can assess and
coordinate a fix before disclosure.

This template is an integration sample, not a supported Neo4j or Microsoft
managed service. Security fixes target the latest version on the default branch.
Include the affected commit, deployment mode, Azure region, and a minimal
reproduction without credentials, tokens, customer data, or tenant identifiers.
